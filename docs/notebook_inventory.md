# Notebook inventory

바탕화면 `kamp`·`final`에 있던 노트북 88개를 모두 확인했습니다.
내용이 완전히 같은 복사본 4개를 제외한 **84개 원본 노트북**을 저장소에 보존했습니다.

노트북은 당시 코드와 출력 셀을 그대로 보존한 **실험 기록**입니다.

새 위치에서 바로 실행되지 않을 수 있습니다. 재현 가능한 최종 실행 경로는
루트 README와 제품별 `run_*.py`를 참고하세요.
